En esta carpeta se encuentran las librerias creadas para la programacion del proyecto. Estas estan programadas en C.
Cada carpeta de librerias contiene los siguientes elementos:

- libreria.h
- libreria_imp.h
- CMakeLists.txt

Para poder usar estas librerias es necesario añadir todos estos archivos a una carpeta en /libs del proyecto de platformio.
